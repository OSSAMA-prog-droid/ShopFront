# ShopFront

React + TypeScript e-commerce storefront. Built with Vite, React Router v6, and Axios.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

## Test

```bash
npm test
```

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `VITE_API_URL` | `http://localhost:4000/api` | Backend API base URL |
| `VITE_WS_URL` | `ws://localhost:4000` | WebSocket server URL |
